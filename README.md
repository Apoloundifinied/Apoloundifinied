## Game dev e criação visual

No **Mutant Factory — Lab Zero**, protótipo para Roblox, desenvolvi em Luau o HUD, o inventário e a progressão baseada em recursos. O projeto também inclui ícones e artes conceituais 2D. A execução ainda precisa ser validada no Roblox Studio.

Uso Photoshop, After Effects, CapCut, Vegas, Boris FX, Sapphire e Canva para edição, composição e motion.
